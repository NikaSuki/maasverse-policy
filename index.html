Privacy Policy – MaasverseTrackerTracker

Last updated: October 11, 2026

1. Application and Developer Information

This Privacy Policy applies to MaasverseTracker, an Android application designed to help users track books, characters, reading progress, ratings, preferences and personal notes related to the works of Sarah J. Maas.

Application name: MaasverseTracker

Developer name: AitorMF

Privacy contact email: acinofelet@hotmail.es

2. Information Collection

MaasverseTracker does not require users to create an account or provide personal information such as their name, email address, phone number or location.

The application does not collect personal information through developer-operated servers. Information entered by users while using the application's features is stored locally on their device.

3. Data Stored on Your Device

MaasverseTracker uses the Android Room persistence library to store application data in a local database on the user's device.

Depending on the features used, this information may include book-related information, character details, reading progress, ratings, preferences and personal notes.

The local database is managed by the application. Users do not need to access or edit the database directly to use the application's features.

The application does not transmit information stored in this local database to the developer or external servers.

4. Data Sharing and Third-Party Services

MaasverseTracker does not sell, rent or share users' locally stored application data with third parties.

The application does not include advertising, analytics, user-tracking services, Firebase or other external services intended to collect or transmit user information.

5. Internet Access

MaasverseTracker's main functionality relies on data stored locally on the device and does not require an internet connection.

The application does not transmit information stored in its local database over the internet.

6. Data Retention and Deletion

Application data remains stored locally on the device until it is deleted through the application's available features, if provided, or removed by clearing the application's storage or uninstalling the application.

Android device backup settings and system behavior may affect whether application data can be restored after deletion or reinstallation.

The developer does not maintain a separate server-side database containing users' locally stored application data.

7. Data Security

MaasverseTracker stores application data in a local database managed through the Android application environment. Access to application data is subject to Android's security mechanisms and the security of the user's device.

8. Children's Privacy

MaasverseTracker does not knowingly collect personal information from children or other users through developer-operated servers. The application does not require users to submit personal information to access its core functionality.

9. Changes to This Privacy Policy

This Privacy Policy may be updated to reflect changes to the application's functionality or applicable legal requirements. Any updates will be published on this page with a revised date.

10. Contact

If you have any questions about this Privacy Policy or the privacy practices of MaasverseTracker, you can contact the developer at:

Email: acinofelet@hotmail.es
